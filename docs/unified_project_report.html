Scientific Project Arc

The current scATAC model is not an isolated experiment. It follows a sequence of tests that separated nucleosome positioning from cleavage bias, exposed the limits of plasma-only conditioning, and motivated cell-type-resolved scATAC labels.

Question
Why move from cfDNA to scATAC?
Observed result
Sequence predicts a global positioning prior, while healthy plasma offers weak lineage contrast.
Interpretation
scATAC fragment geometry supplies direct cell-type-resolved dyad labels.
Limitation
scATAC labels still require depth, insert preservation, and orthogonal validation.

Phase 1: sequence carries a nucleosome-positioning prior

A single-head dilated convolutional model trained on pooled healthy-plasma cfDNA endpoint density reached approximately 0.679 held-out profile correlation and 0.624 count correlation on test chromosomes chr1 and chr9. Predictions recovered the approximately 190 bp nucleosome repeat, with the FFT maximum appearing in the 200 bp bin. This is important because a base-composition shortcut should not reproduce multi-nucleosome periodicity on chromosomes excluded from training.

Established Sequence contains a reproducible, cell-type-invariant positioning component.

Phase 2: positioning is not merely nuclease end-motif bias

Question
Could local nuclease sequence preference explain the profile result?
Observed result
The pure 4-mer floor reaches 0.213; L8 reaches 0.674.
Interpretation
The +0.461 gap is positioning signal beyond local cleavage preference.
Limitation
This ablation separates bias from positioning, not shared from cell-type-specific positioning.

Phase 3: conditioning infrastructure was valid, but the biological contrast was not

Identity-initialized FiLM conditioning was implemented and verified to start with identical outputs across conditions. However, BH01 and IH01 are both healthy plasma dominated by hematopoietic cfDNA. Differences between them primarily test sample or technical variation, not distinct cell-type nucleosome landscapes. The honest phase-3 result was therefore an architecture deliverable, not a claim of cell-type biology.

Open

A model can predict the invariant backbone well and still learn no cell-type residual. Absolute profile correlation alone cannot establish conditioning success.

Cell-Type-Specific Label Construction

Different cell types have different nucleosome occupancy. The dyad target is therefore constructed separately from each cell type's fragments; GM12878 is a benchmark, not a universal nucleosome label.

Head 1: accessibility cutsites

For each fragment, add its multiplicity at the shifted 5-prime cut positions:

plus = start + 4
minus = end - 4 - 1

This follows the ChromBPNet Tn5 convention. Do not apply a second shift downstream.

Head 2: nucleosome dyads

Keep mono-nucleosomal fragments with default insert length 150 <= L < 250 and add multiplicity at:

dyad = floor((start + end) / 2)

Optional Gaussian smoothing materializes dense chromosome arrays; unsmoothed aggregation stays sparse.

Implementation and storage

chrombpnet-build-tracks uses Polars lazy scans and streaming group-by aggregation to avoid whole-genome dense arrays for ordinary track construction. It filters to chr1-22, X, and Y by default and writes base-resolution bigWigs with pyBigWig. Large artifacts live below /mnt/data/jganbat/chrombpnet/data; the repository's data path is a symlink to that NFS-backed directory.

Model and Training Method

The active owned workflow is PyTorch-only and follows Prima's internal conventions: Python 3.11, uv, GPU/CPU extras, Polars preprocessing, and W&B experiment tracking.

Input

One-hot DNA sequence, default 2,114 bp. Training regions come from peaks plus a 0.1 negative-sampling ratio.

Shared trunk

Conv1D 4 → 512, kernel 21, followed by 8 residual dilated layers, kernel 3, dilation 2 through 256.

Outputs

Two independent profile/count heads. Each profile uses a 75 bp convolution and center-crops to 1,000 bp; each count head pools trunk features.

Four-part multitask objective

L = NLL(acc profile) + w_count MSE(acc log-count) + w_nuc-profile NLL(nuc profile) + w_nuc-count MSE(nuc log-count)

The profile terms are multinomial negative log likelihoods, which learn the distribution of signal within each output window. Count terms are mean-squared error on log total signal. The current defaults set all three weights to 1.0. This makes --nucleosome-profile-weight the most direct first lever for the weak profile shape result, but weight changes must be judged on held-out shape metrics rather than loss alone.

Data handling and leakage control

  • Training examples share sequence crop and reverse-complement transformation across both labels.
  • Training uses jitter up to 500 bp and reverse-complement augmentation; validation does not augment.
  • Chromosome partitions prevent nearby sequence windows from leaking between splits.
  • The current fold contains 19 training chromosomes, 2 validation chromosomes, and test chromosomes chr1, chr3, and chr6.
  • PyTorch DataLoader uses 16 workers by default, persistent workers, prefetch factor 2, and pinned memory when CUDA is available.

Why cell-type-specific modeling remains viable

Depth-controlled cross-cell-type correlation divided by the split-half expectation is 0.68 for deep pairs. This indicates that roughly one third of reproducible positioning differs among cell types rather than being shared. Differential calling identified 841 strong one-versus-rest sites in a 20-cell panel. The signal therefore exists; the model has not yet captured most of it.

Selection rule for future multicell models. Do not select a model only because absolute nucleosome profile correlation rises. Require improvement in deviation correlation and repositioning direction at called sites under a shared chromosome holdout.

Decision Roadmap

The next work should convert the current benchmark into biological evidence before adding corpus scale. Each stage has an explicit pass criterion and a decision it unlocks.

ExperimentExport GM12878 predicted accessibility and dyad bigWigs; inspect TSS, CTCF, high-signal, and error loci.
Success criterion / decisionProfiles are correctly oriented, positioned, and nonblank. Confirms whether the weak nucleosome Pearson reflects smoothing, phase shift, or diffuse predictions.
ExperimentTrain K562 and MCF7 with identical hyperparameters and their own Pierce2021 labels.
Success criterion / decisionReproduce comparable count and profile metrics on shared held-out chromosomes. Establishes whether GM12878 behavior is cell-line-specific.
ExperimentSweep dyad smoothing, nucleosome profile weight, profile-kernel/head capacity, and optional cfDNA trunk transfer.
Success criterion / decisionIncrease held-out nucleosome profile Pearson and JSD improvement without reducing count performance or strand consistency.
ExperimentTrain shared-trunk multicell baselines with per-cell head pairs and globally shared chromosome folds.
Success criterion / decisionBeat separate-model efficiency while retaining per-cell absolute metrics. Determines whether shared sequence grammar helps.
ExperimentEvaluate cell-type deviation and shift direction at the 841 differential sites; compare per-cell, FiLM, and hybrid heads.
Success criterion / decisionDeviation and shift-direction correlations rise beyond the current 0.217 and 0.067 called-site baselines. Establishes real conditioning.
ExperimentAdd GENCODE TSS aggregation and orthogonal ENCODE MNase/DNase comparisons for GM12878 and K562.
Success criterion / decisionRecover +1/+2/+3 nucleosome arrays and agreement with assay-orthogonal tracks. Supports biological validity.
ExperimentExpand through a QC manifest to deep heart, kidney, retina, brain, liver, lung, endocrine, and tumor samples.
Success criterion / decisionStable metrics across lineage-balanced samples and a true entire-cell-type holdout. Tests generalization beyond cell lines.

Highest-value immediate comparison

The most informative next experiment is not a longer GM12878 run. It is a matched three-cell-line matrix: GM12878, K562, and MCF7, same chromosome fold, same optimization, each with its own cutsite and dyad tracks. That matrix separates model weakness from label/cell-type effects and creates the first controlled input to a shared-trunk multicell model.

Known limitations

  • The current completed baseline is one cell type and one fold; it does not establish cross-cell-type or unseen-cell-type generalization.
  • The nucleosome target is derived from scATAC fragment centers, not orthogonal MNase measurements.
  • Bias correction for the accessibility head and blacklist subtraction remain deferred in the owned multitask path.
  • The flat-profile baseline is necessary but weak; stronger profile baselines are still needed.
  • Reverse-complement count consistency is not a full proof of exact profile equivariance.
  • Several historical multicell findings come from separate models and must not be attributed to the GM12878 checkpoint.

Glossary

Cutsite
A base-position estimate of a Tn5 insertion after strand-specific coordinate shifting.
Dyad
The estimated nucleosome center, represented here by the midpoint of a mono-nucleosomal ATAC fragment.
Profile
The normalized base-resolution distribution of signal inside the 1,000 bp output window.
Count
The total target signal in an output window, modeled on a log scale.
JSD
Jensen-Shannon divergence between predicted and observed distributions; lower is better.
Profile Pearson
Linear correlation between predicted and observed base-resolution shapes within regions.
Count Pearson
Linear correlation of predicted and observed window-level totals across regions.
Reverse-complement consistency
Agreement when the same locus is presented in the opposite sequence orientation.
Chromosome holdout
A split where entire chromosomes are excluded from training to reduce sequence leakage.
Cell-type deviation
A cell type's normalized profile minus the leave-one-out consensus profile, isolating specific positioning from the shared backbone.
Split-half ceiling
Reproducibility between independent halves of the observed data, approximating the achievable upper bound.
NRL
Nucleosome repeat length, observed as a roughly 190-200 bp periodicity in nucleosome arrays.
