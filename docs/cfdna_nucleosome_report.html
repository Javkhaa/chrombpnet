01 · The data

~200× healthy plasma, realigned natively to hg38

Deep healthy cfDNA from Snyder 2016, realigned from FASTQ against the same hg38 reference the scATAC corpus uses — one coordinate space, no reconciliation. Paired-end throughout; fragments are proper pairs, MAPQ ≥ 30, 50–250 bp, duplicates removed.

Label track — per-base fragment-endpoint density: each fragment's 5′ (start) and 3′ (end−1) nuclease cut site, no Tn5 shift. cfDNA endpoints are the direct analogue of Tn5 insertion sites, so ChromBPNet's loss transfers 1:1. The endpoint density itself carries a 195.6 bp periodicity (whole-chromosome FFT) — the target is biologically meaningful, not noise.

An end-to-end test (FASTQ → align → fragments → track, all 24 chromosomes checked for signal + periodicity) caught a silent chromosome-loss bug — lexical vs karyotypic sort was dropping 13/24 chromosomes from the bigWig — before it reached training data.

02 · The model

The repo's exact trunk, one head, unchanged loss

SeqNucleosomeModel reuses the dilated-conv trunk verbatim — first conv k=21, 8 residual dilated layers, 512 filters (~1 kb receptive field, ~5 nucleosomes) — with a single ProfileCountHead. One head, because bulk cfDNA has no accessibility channel. The head keeps the ChromBPNet loss untouched: profile multinomial NLL + count MSE on log total endpoints.

Splits are by chromosome, not random window — adjacent windows share the same nucleosome array, so random splits leak. Test chr1, chr9 (untouched until frozen), valid chr8/chr10, train the rest, chrY excluded. 1.95M train / 260k valid / 308k test windows.

04 · Independent validation

Reproduces positioning against references it never trained on

Two external checks on held-out chr1+chr9: the canonical TSS nucleosome array, and agreement with Snyder's own published dyad calls. Phase-1 numbers reconfirmed unchanged (0.679 / 0.624 / 200 bp).

TSS array — the canonical proof of sequence-encoded positioning

Aggregate predicted endpoint profile around 2,838 held-out protein-coding TSS, strand-oriented, vs the observed cfDNA track. A phased +1/+2/+3 nucleosome array emerges downstream from sequence alone — trough at the protected +1 nucleosome, linker peak beyond it — matching the observed cfDNA at r = 0.79 (downstream periodicity 182 bp).

Cross-assay MNase — honest negative

The direct-assay check (Gaffney B-cell MNase, Song) does not co-register with plasma cfDNA — model r −0.10, but the observed-data ceiling is also ≈ 0 (wrong sign), so there is no agreement to recover even before the model. This is an assay + cell-type domain gap (apoptotic-nuclease cutting in mixed-lineage plasma vs micrococcal digestion in one cultured cell type), a property of the data — not a model failure. A matched, independent nucleosome map remains the open validation step.

05 · Ablation

Is positioning just cut-site bias? No.

The 5′ end 4-mer reads out the apoptotic nuclease's sequence preference — the published end-motif signal. If the model were only learning that, its ceiling would be the pure 4-mer floor. Sweeping trunk depth (≈ receptive field) shows it is far above:

Held-out profile correlation vs receptive field chr1 + chr9 · scale 0 → 0.80
The pure 4-mer end-motif predicts endpoint density at only 0.213; the model reaches 0.63–0.67 — a +0.46 gap that is genuine nucleosome positioning, not local cleavage preference. Most of it lives at ~100 bp (one nucleosome): L=1 already hits 0.63; extending to ~1 kb adds only +0.04 of multi-nucleosome phasing.

07 · Phase 3 — cell-type conditioning

Machinery built, identity-safe — result data-blocked

Infrastructure ready · biological claim blocked

CondSeqNucleosomeModel adds per-condition FiLM modulation to the phase-1 trunk, identity-initialized (γ=β=0 → scale 1, bias 0): at init, two conditions produce identical output, so the model starts equal to the unconditioned baseline and can only learn per-condition deviation. This is the built-in guard against the Role-b collapse (a conditioned model regressing to the invariant backbone).

The honest limitation: BH01 and IH01 are both healthy plasma, and plasma cfDNA is compositionally dominated by one lineage (hematopoietic) — the very fact that made cell-type deconvolution hard. Conditioning on two healthy samples measures sample-to-sample/technical difference, not cell-type deviation. Phase 3's deliverable is the infrastructure, not a biological claim — and the protocol rule it enforces: evaluate on cell-type deviation, never absolute prediction.

08 · Scope

What this establishes — and what it doesn't

Establishes

  • The global, cell-type-invariant sequence → positioning signal — ~50% of positioning is sequence-encoded; this captures the sequence part.
  • NRL recovery from sequence on unseen chromosomes — the sharp, GC-proof test.
  • Positioning is +0.46 above the cut-site bias floor, largely a ~100 bp local grammar.
  • Closes Track 1's dead end: the per-base positioning prior now exists.

Does not yet address

  • Cell-type-specific deviation — needs contrastive data plasma can't supply.
  • Whether conditioning learns real residual vs merely the invariant backbone (Role-b failure mode).
  • Sharper external checks: TSS +1/+2/+3 array, agreement with Snyder's published dyad calls.
